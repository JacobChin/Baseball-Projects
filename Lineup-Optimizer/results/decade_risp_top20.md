# RISP One-Run Clone Leaderboards By Decade

Each entry is a nine-copy lineup of one player-season. The objective is the probability of scoring at least one run before three outs when the starting state is drawn from the empirical 2025 distribution of all 18 RISP base/out states.

## Method

- Eligibility: at least 600 common plate appearances.
- Candidate screen: the existing 2,000-trial all-season sweep.
- Finalist simulation: 20,000 trials for the top 125 screened seasons in each decade.
- Deterministic seed: `202610291`.
- Actual strikeouts and stolen bases are retained; missing CS is standardized to a 75% success rate.
- Seasons through 2019 use neutral BIP mix, Sprint Speed, and home-to-first inputs.
- Eligible 2021-2025 seasons use their cached season-specific Savant inputs.
- Contextual walks are disabled for a consistent cross-era comparison.
- This uses a fixed modern run environment and is not era-adjusted.

## Interpretation

Close ranks should not be treated as exact ordering when their confidence intervals overlap. The staged search reduces computation, while the complete 2,000-trial screen and 125 finalists per decade protect against obvious candidate omissions.

The CSV containing the underlying finalist results is stored under `results/data/` in the public repository so the main results folder remains easy to browse.
